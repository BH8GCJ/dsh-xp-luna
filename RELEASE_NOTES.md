# XP Luna v1.3.14 — readable “推荐” chip

- **Recommended chip in question cards**: the ask-user-question card marks a
  recommended option with a small chip whose background is the sidebar accent
  and whose text colour is the info-button fill. Under Luna both resolved to
  blue, so the label vanished into the chip. The chip now keeps the XP blue
  `#316AC5` background and uses white text.
- **Windows caption strip** (1.3.13): the native overlay is a solid rectangle,
  so the whole 40px strip now uses the same `#2A6FE0` and the glyphs are white;
  Linux keeps the Luna gradient.
- **HARNESS badge** (1.3.12): white pill with dark ink in both colour schemes.

Update, then fully quit and reopen the app — the client bundle is loaded at
boot, so a page refresh alone is not enough.
